Docker Compose + Traefik

Stack com validador fixo, réplicas follower atrás do Traefik e autoscaler por métricas Prometheus.

cp .env.example .env
make docker-up
curl -s http://127.0.0.1/health
make docker-ps
make docker-scale N=3   # scale manual
make docker-load PIXIE_URL=http://127.0.0.1 N=1000 WORKERS=32
make docker-down

Arquivos: compose.yaml, Dockerfile, docker/entrypoint.sh, docker/autoscaler/. O validador grava genesis no volume pixie-config; cada follower usa volume anônimo em /data.

Autoscaler: SCALE_UP_RPS / SCALE_DOWN_RPS em .env (ver .env.example). Requer Docker no host (socket via docker-socket-proxy).

Keystore vs validator-key

  • Keystore: assina payments pelo payer; login de conta no explorer; close de merchant.
  • Validator-key: produz blocos; assina account create; close de person; viewer audit.

Limitações do MVP

  • PoA sem BFT
  • P2P sem NAT traversal
  • Contas internas (sem banco real)
