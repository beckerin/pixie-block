Consenso PoA

Proof of Authority simples: validadores listados no genesis; um produtor assina blocos.

Genesis

  • validators[] com id + public_key
  • block_time_seconds (demo: 5)
  • max_txs_per_block
  • chain_id

Producer vs follower

ModoComoCapacidades
Producer --validator-key aponta para a chave do validador Produz blocos; cria contas; close de person; audit via pkey do validator
Follower --validator-key "" (como make run-node2) Recebe blocos/TXs via P2P; API de leitura; create account → 403

Ciclo de bloco

  1. Espera block_time_seconds.
  2. Drena mempools (creates, payments, closes) até o limite.
  3. Monta bloco com previous hash, assina Ed25519.
  4. Persiste, aplica estado, gossip.
PoA MVP: sem BFT formal, sem rotação elaborada de líder. Adequado a demos e ambientes controlados.

P2P

  • TCP + mensagens JSON
  • Peers via --peer (lista separada por vírgula)
  • Sem NAT traversal automático
