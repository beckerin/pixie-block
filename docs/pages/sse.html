SSE / chain

GET /v1/chain é um stream Server-Sent Events para o explorer — não um JSON único.

GET /v1/chain text/event-stream

Comportamento

  • Upgrade SSE; push inicial imediatamente.
  • Polling interno ~1s; reenvia só se o height mudou.
  • Viewer opcional via ?pkey= (preferível) ou X-Private-Key.

Eventos

EventConteúdo
ChainInfoHTML: chain id + height
LatestBlockJSON do bloco atual (redigido por viewer)
PreviousBlockJSON do height−1 ou texto “nenhum bloco anterior”
ViewerPanelHTML do painel de ações (vazio / conta / audit)
BalanceHTML do saldo próprio ou lista audit; vazio se anônimo

ViewerPanel e Balance

ViewerPainelSaldo
AnônimoPlaceholder vazioVazio
ContaTX + close se merchantSaldo da conta
AuditCriar, TX, close person/merchantTodas as contas

Inspecionar com curl

curl -N 'http://localhost/v1/chain'
curl -N 'http://localhost/v1/chain?pkey=<pkey>'
O explorer usa htmx-ext-sse com sse-swap nos elementos ChainInfo, LatestBlock, PreviousBlock, ViewerPanel, Balance.
