Getting started

Suba um nó local, abra o explorer e explore a API documentada.

Documentação completa em /v1/docs/. Explorer HTMX em /. Referência interativa em API Reference.

Pré-requisitos

  • Go 1.22+
  • Make

Setup

# Gerar genesis, keystore e validator-key de demonstração
make genkeys

# Compilar
make build

# Testes
make test

Rodar um nó

make run

Com o Makefile padrão:

  • API HTTP: http://localhost:80
  • P2P: :90
  • Explorer: http://localhost/
  • Docs: http://localhost/v1/docs/

Primeira transação

Valores em centavos. Impostos vêm de config/taxes.json via tax_codes no item (não envie splits no body).

curl -s -X POST http://localhost/v1/transactions \
  -H 'Content-Type: application/json' \
  -d '{
    "payer": "merchant_001",
    "payee": "person_001",
    "items": [
      {
        "description": "Pagamento",
        "amount": 1000,
        "tax_codes": []
      }
    ]
  }'

Após o block time (~5s no genesis), a TX entra em um bloco. Consulte:

curl -s http://localhost/v1/blocks/latest | jq .
curl -s http://localhost/v1/accounts/person_001/balance | jq .

Cluster local (2 nós)

make run-cluster
  • Nó 1 (produtor): API :80, P2P :90
  • Nó 2 (follower): API :81, P2P :91 → peer 127.0.0.1:90
