Contas

Três tipos on-chain: person, merchant e treasury. Criação e encerramento seguem regras distintas.

Tipos

TypeSignificadoNotas
personPessoa físicaPayee não pode receber tax_codes
merchantPessoa jurídicaPode pagar/receber com impostos do genesis
treasuryÓrgão fiscalDestino de splits; não se encerra via API

Saldos são inteiros em centavos. Contas novas nascem com saldo 0.

Listar e consultar

GET /v1/accounts
GET /v1/accounts/{id}/balance

Públicos: retornam IDs, tipos e saldos em claro.

Criar conta

POST /v1/accounts

Somente em nó produtor (com validator key). Gera par Ed25519, assina create com o validador, coloca no mempool de creates e persiste a chave no keystore.

curl -s -X POST http://localhost/v1/accounts \
  -H 'Content-Type: application/json' \
  -d '{"id":"person_005","type":"person"}'

Resposta inclui private_key uma vez — guarde-a. Tipos aceitos: person | merchant (não treasury).

Follower sem --validator-key responde 403 em create.

Encerrar conta

DELETE /v1/accounts/{id}

Person

  • Somente nó validador.
  • Saldo residual vai para destination (opcional) ou treasury padrão do ledger.
  • Body: {"destination":"person_002"} (opcional).

Merchant

  • Exige X-Private-Key (ou ?pkey=) da própria conta.
  • Saldo deve ser 0.
  • Sem destination.
# Merchant (saldo zero)
curl -s -X DELETE http://localhost/v1/accounts/merchant_002 \
  -H 'Content-Type: application/json' \
  -H 'X-Private-Key: <pkey-base64>' \
  -d '{}'

Ordem no bloco

O produtor inclui, nesta ordem: account creates → payments → account closes.
